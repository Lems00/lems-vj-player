# Lems VJ Player

Console DJ / VJ à quatre platines pour Mac, Windows et Android. Les sources sont YouTube (lecteur officiel) et les fichiers audio et vidéo de l'utilisateur. Le son et l'image partent ensemble en sortie, et les appareils se connectent entre eux sur le Wi-Fi.
